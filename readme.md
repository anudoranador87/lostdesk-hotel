# 🧳 LostDesk — Gestión de Objetos Perdidos

> Herramienta interna para hoteles. Registra, busca y gestiona objetos perdidos desde cualquier punto del establecimiento — sin subir al altillo.

![Estado](https://img.shields.io/badge/estado-en%20desarrollo-yellow)
![Stack](https://img.shields.io/badge/stack-HTML%20%7C%20CSS%20%7C%20JavaScript-blue)
![Storage](https://img.shields.io/badge/storage-localStorage-orange)

---

## 🧩 El problema real

En muchos hoteles, los objetos perdidos se gestionan con un folio pegado en una caja del almacén.

Cuando un cliente llama por teléfono preguntando por su objeto, el recepcionista **no puede responder sin subir físicamente al altillo** a buscarlo entre bolsas, cajas y objetos sueltos sin clasificar.

Resultado: tiempo perdido, cliente esperando, y sin garantía de encontrar nada.

**LostDesk resuelve eso.**

---

## ✅ Qué hace

- 📝 **Registrar** objetos perdidos con: habitación, fecha, descripción, tipo y ubicación en almacén
- 🔍 **Buscar** por habitación, fecha o descripción — desde recepción, en segundos
- 📦 **Clasificar** por tipo: bolsa, caja, objeto suelto, documento, electrónico
- 🔄 **Gestionar estados**: Pendiente · Reclamado · Enviado · Sin dueño
- 👥 **Multi-rol**: Recepción, Housekeeping y Management desde el mismo sistema

---

## 🛠️ Stack

- HTML5 semántico
- CSS3 — Flexbox, responsive, variables CSS
- JavaScript vanilla — sin dependencias externas
- localStorage — persistencia sin base de datos

---

# 🧳 LostDesk — Lost & Found Management

> Internal hotel tool. Register, search and manage lost items from anywhere in the property — no more trips to the storage room.

![Status](https://img.shields.io/badge/status-in%20development-yellow)
![Stack](https://img.shields.io/badge/stack-HTML%20%7C%20CSS%20%7C%20JavaScript-blue)
![Storage](https://img.shields.io/badge/storage-localStorage-orange)

---

## 🧩 The real problem

In many hotels, lost items are tracked with a handwritten note taped to a box in the storage room.

When a guest calls asking about their belongings, the receptionist **cannot answer without physically going up to the storage area** to search through unsorted bags, boxes and loose items.

Result: wasted time, guest on hold, and no guarantee of finding anything.

**LostDesk solves that.**

---

## ✅ What it does

- 📝 **Register** lost items with: room number, date, description, type and storage location
- 🔍 **Search** by room, date or description — from the front desk, in seconds
- 📦 **Classify** by type: bag, box, loose item, document, electronic
- 🔄 **Manage status**: Pending · Claimed · Shipped · Unclaimed
- 👥 **Multi-role**: Reception, Housekeeping and Management in one system

---

## 🛠️ Stack

- Semantic HTML5
- CSS3 — Flexbox, responsive, CSS variables
- Vanilla JavaScript — no external dependencies
- localStorage — persistence without a database

---

## 👥 Users

| Role | Can do |
|------|--------|
| 🏨 Reception | Register, search, update status |
| 🛏️ Housekeeping | Register items found in rooms |
| 📋 Management | View full history |
